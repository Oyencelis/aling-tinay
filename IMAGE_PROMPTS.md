# IMAGE_PROMPTS.md

All photography on this site was generated with the prompts below and saved to the exact
paths the code expects. To redo a shot, run the prompt in Midjourney / Flux / Imagen /
GPT-image at the stated aspect ratio, export **WebP**, and overwrite the file.

**Style rules used everywhere:** natural window light from the left, shallow depth of
field, real textures (salt grains, oil sheen, crumbs, wrinkles), slightly imperfect
arrangement, flat coloured paper backdrop that matches the scene colour. No plastic
3D-render sheen, no text, no watermarks, no logos.

Palette for backdrops: peanut cream `#F6EBD9` · roasted brown `#3B2314` · corn yellow
`#F2B705` · chili red `#D93A25` · pandan green `#3F7D4E`.

## Swap in real photos

The fastest replacement is your own phone photo of the actual product:

1. Shoot on a flat sheet of coloured paper near a window (light from one side).
2. Crop square (`1:1`) for products, `3:4` for the Mani/Cornick scenes, `16:9` for the
   storefront and process shots.
3. Export WebP, keep the same filename, drop it into `public/images/...`.
4. No code changes needed. Update alt text in `data/products.ts` if the photo changes
   meaningfully (cards build alt text from the product name and Tagalog line).
